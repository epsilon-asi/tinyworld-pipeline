# Appendix A — Tripo API v3 Reference (as used by this project)

Source of truth: `https://developers.tripo3d.ai/en/docs/*` (pages `models-texture`, `files`,
`files-presign`, `task-query`, `account`, `quick-start` read on 2026-11-02). Items marked
**[unverified]** are not stated in the docs and are resolved by Spike S1. Base URL:
`https://openapi.tripo3d.ai/v3` (**`.ai`, not `.com`**). Auth: `Authorization: Bearer {api_key}`;
keys are issued at `developers.tripo3d.ai/en/keys` and start with `sk-`.

## 1. Endpoint catalogue

| Area | Endpoint | Used in |
|---|---|---|
| Files | `POST /files` (multipart `file`; images JPEG/PNG ≤ 20 MB; models GLB/GLTF/FBX/OBJ/STL ≤ 150 MB) → `data.file_token` | v1 |
| Files | `POST /files/presign` `{"format":"glb"}` → `presigned_url` (PUT raw bytes, `Content-Type: application/octet-stream`, no auth), `file_token`, `expires_in` (do not rely on it; on expiry request a new presign); recommended > 60 MB. Formats: images jpeg/jpg/png/webp/bmp/tiff; models glb/gltf/fbx/obj/stl/3mf/usdz | v1 |
| Models | `POST /models/texture` → `data.task_id` | v1 |
| Models | `POST /models/convert` | future |
| Models | `POST /models/import` `{model:"default", input:file_token}` → task_id (makes an uploaded file addressable as a task) | optional in v1 (S1 decides if texturing via import-task behaves differently from direct file_token) |
| Tasks | `GET /tasks/{task_id}` → `TaskDetail` | v1 |
| Tasks | `POST /tasks/list` `{"task_ids": ["…", …]}` (≤ 100 ids per request; Bearer auth) → `data.tasks` = object keyed by `task_id` whose values have the `GET /tasks/{id}` shape, `data.missed` = string array of ids not owned by the account (`null`/omitted when all were found); an invalid id *format* fails the whole request (verified against docs page `task-batch-query` 2026-11-02) | v1 (`gp tripo task` batch; ambiguous-create recovery) |
| Account | `GET /account/balance` → `{balance, frozen}` (`frozen` = reserved by in-progress tasks) | v1 (`gp doctor`, `gp tripo balance`) |
| Account | `GET /account/usage` → `[{task_id, type, credits_consumed, created_at}]` | optional (`gp tripo usage`, cost audit) |
| Generation | `POST /generation/text-to-model`, `image-to-model`, `multiview-to-model` | future |
| Image | `POST /generation/text-to-image`, `image-to-image`, `image-to-multiview`, `edit-multiview` | future |
| Mesh | `POST /mesh/segment`, `/mesh/complete`, `/mesh/decimate` | future |
| Animation | `POST /animations/rig-check`, `/animations/rig`, `/animations/retarget` | future |

## 2. Envelope

Success: `{"code": 0, "data": {...}}`. Error: `{"code": <non-zero>, "status": "error", "message": "...",
"suggestion": "...", "request_id": "..."}`. `data` only on success; `message/suggestion/request_id`
only on failure. HTTP status may still be 200 with a non-zero `code` → always check `code`.

## 3. `POST /models/texture` parameters

| Param | Type | Notes |
|---|---|---|
| `input` | string, required | `task_id` of a prior task, `file_token` from upload, or public URL |
| `model` | string | texture model version: `v3.5-20260815` (newest), `v3.0-20250812` (default), `v2.5-20250123` |
| `texture_prompt` | object | `text` / `image` / `images` mutually exclusive; `style_image` may accompany `text`. Optional if the input was generated by Tripo. **`style_image` is an object** `{"file_token": …}` or `{"url": …}` (≥ 256 px recommended). `image`: file_token or URL string. **`images`: view-key array** `[{"front": tok}, {"left": tok}]` (`front` required, ≥ 2 views, omit missing; values may be token/URL strings or `{file_token}`/`{url}` objects) or positional 4-array `[front, left, back, right]` with `null`/`""` for missing; forms must not be mixed |
| `pbr` | bool, default true | PBR maps |
| `texture_seed` | int | same seed → identical textures |
| `texture_alignment` | `original_image` (default) \| `geometry` | only relevant with image guidance |
| `texture_quality` | `fast` (requires `v3.5-20260815`, else API error `1004`; same texture size as standard) \| `standard` (default) \| `detailed` (HD) \| `extreme` (8K) |
| `bake` | bool, default true | bake advanced material effects into base textures |
| `delight` | bool, default true | remove baked lighting from reference (v3.5 only) |
| `part_names` | string[] | from a prior segmentation task |
| `compress` | `geometry` | meshopt compression — **never set** (we must parse the GLB) |

Response: `{"code":0,"data":{"task_id":"task_…"}}`.

**[unverified]** Whether `image`/`images` guidance is accepted when `input` is a `file_token` (R-02).
**[unverified]** Whether geometry/UVs of the uploaded mesh are preserved (R-01). **[unverified]** Face
count limits for texturing (none documented; 150 MB file cap).

## 4. `GET /tasks/{task_id}` response (`data`)

```json
{"task_id":"task_abc123","type":"texture_model","status":"success","progress":100,
 "output":{"model_url":"https://cdn.tripo3d.ai/output/model_pbr.glb","rendered_image_url":"https://…/preview.png"},
 "credits_consumed":20.0,"created_at":"2026-04-28T12:00:00Z","completed_at":"2026-04-28T12:01:30Z"}
```

Statuses: `queued` (progress 0), `running`, `success`, `failed` (+`error_code`, `error_message`),
`cancelled`; legacy responses may return `banned` or `expired` (terminal failures) and `unknown` (keep
polling, bounded). Poll every 2 s and never more than 1 request/s; typical generation 10–120 s.
**Output URLs are signed CDN links that expire about 5 minutes after retrieval** — download immediately,
re-`GET /tasks/{id}` for a fresh URL. For texture tasks whose `input` was a `file_token`/URL, `output`
also carries `normalize_scale` (number; `normalized = original × normalize_scale`, `1.0` = unscaled but
possibly translated) and, when available, `normalize_translation` (`[tx, ty, tz]`). Rate limit for
model-processing tasks (shared with format conversion): 5 in parallel.

## 5. Upload flows

Small (≤ 60 MB): `curl -F "file=@static.glb" /v3/files` → `file_token`.
Large: `POST /files/presign {"format":"glb"}` → `PUT presigned_url` with raw bytes
(`Content-Type: application/octet-stream`, no auth) → use `file_token`.

Reference images: `POST /files` with PNG/JPEG → `file_token`; place token in `texture_prompt.style_image`
/ `image` / `images.*`.

## 6. Credits (for `tripo/budget.py` defaults; official pricing table read 2026-11-02 — S1 records actuals)

`/models/texture`: `fast 10`, `standard 10`, `detailed (HD) 20`, `extreme (8K) 30` credits; no surcharge
documented for a style image. 1 credit = US$0.01. Defaults: `fast 10, standard 10, detailed 20,
extreme 30, style_image 0`. Always prefer `credits_consumed` from the task detail.

## 7. Client behaviour summary (normative in `10` §3)

- Treat `code != 0` as `TripoApiError`; map 401/403, 429 (`Retry-After`), 5xx, network errors.
- Retry only idempotent calls (GET, uploads, downloads) automatically; task creation is retried only
  when the failure is provably pre-send (connection refused) — otherwise raise
  `TripoAmbiguousCreateError` and let `POST /tasks/list`-based recovery handle it.
- Persist `task_id` immediately after creation for resume.
- Region: international keys work against `openapi.tripo3d.ai`; `base_url` is configurable for any
  regional host Tripo may add.
