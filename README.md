# grounded-pipeline (`gp`)

Upres and retexture already-rigged, already-animated 3D models into one consistent, hand-painted
art style, and deliver Unity-ready FBX + textures + manifest with the animations intact.

```
source FBX ─▶ prepare (Blender: subdivide, unwrap, fingerprint rig)
           ─▶ texture (Tripo API: prompt + style image on a static copy of the mesh)
           ─▶ verify  (did Tripo keep our UVs? choose extract or bake)
           ─▶ apply   (pull textures from the GLB, or bake them onto our mesh)
           ─▶ export  (Blender: FBX + companion animation clips; rig fidelity check)
           ─▶ handoff (manifest.json; copy to Unity; C# postprocessor builds URP materials)
```

The rigged file never leaves Blender. Only a static, unrigged copy goes to the texturing provider.

## What is and is not in this repository

The **tool is open source** (MIT). The **assets are not**: the entire asset library tree
(`library/` — vendor models, reference images, prompts, intermediates, outputs, state) is
git-ignored, and a pre-commit hook refuses to stage anything under it. The only tracked assets are
the tiny synthetic fixtures under `tests/fixtures/`, generated by `tools/make_fixtures.py`.

## Requirements

| Tool | Version | Notes |
|---|---|---|
| macOS (Apple Silicon) | 13+ | primary host; Linux for CI; Windows host deferred (ADR-0002) |
| Python | 3.12 or 3.13 | managed by `uv` |
| [uv](https://docs.astral.sh/uv/) | ≥ 0.8 | `brew install uv` |
| [just](https://github.com/casey/just) | ≥ 1.0 | `brew install just` or `uv tool install rust-just` |
| Blender | **4.5 LTS** | install from blender.org (Homebrew casks ship 5.x, which is refused) |
| Tripo API key | paid tier | `TRIPO_API_KEY` in `.env`; keys start with `sk-` |
| Unity | 6000.x URP | on any machine; imports `output/<model>/` via the bundled Editor package |

## Development

```bash
just setup       # uv sync --all-extras && pre-commit install
just ci          # ruff + mypy --strict + import-linter + pytest with 80 % line/branch/function gates
just test-blender  # integration tests against a real Blender (auto-detected on macOS)
```
